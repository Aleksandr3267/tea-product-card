# Teaboom — карточка товара «Ананасовый улун»

Тестовое задание: верхняя часть карточки товара интернет-магазина Teaboom.ru.

## Запуск

Сборка не нужна — откройте `index.html` в браузере.

## Стек

HTML5, CSS (custom properties, Grid, Flexbox, адаптивная вёрстка), чистый JavaScript (ES6), без фреймворков и библиотек.

## Структура

```
index.html      - разметка
css/style.css   - стили (токены в :root, адаптив в конце файла)
js/main.js      - данные фасовок и переключение
assets/
    ananasovij-ulun.webp   - изображение товара
    bg.webp   - фоновое изображение страницы
```

## Что реализовано

- Изображение, название, категория, выбор фасовки, артикул, цена, старая цена, скидка в %, кнопка «В корзину», краткое описание.
- Переключение фасовки меняет цену, старую цену, процент скидки, артикул и выбранное состояние.
- Фасовки — доступные radio-кнопки (работает с клавиатуры, виден focus-ring).
- Увеличение изображения товара в модальном окне (lightbox) с закрытием по Escape и клику вне изображения.
